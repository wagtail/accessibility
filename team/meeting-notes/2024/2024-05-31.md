* Update on GSoC 2024 alt text capabilities project - Chiemezuo
  - We've been working on some changes to the default Wagtail image model and a new streamfield ImageBlock to encourage good alt text practices
  - Propose adding a new image description field to the image model that will be used for a general description of the image. Will be used as alt text inside the admin. This way editors using screenreaders have a representation of the image too
    + For now, this has to be filled manually. Later during the internship we want to create an AI integration that can automatically suggest descriptions
  - Chiemezuo shows us his proof-of-concept of a new ImageBlock with an alt text field and a checkbox to mark the image as decorative.
  - The changes are quite big and fundamental, hence they have to go through the RFC process to be accepted into Wagtail.
  - Our draft RFC is now in a state that we are happy to receive wider feedback from the accessibility team before officially creating a new pull request in the [wagtail/rfcs](https://github.com/wagtail/rfcs) repository
